# 未対応のテスト種別・制約

このドキュメントは、AI Test Driver で未対応のテスト種別と制約を追跡するために使います。

## 未対応のテスト種別

- [ ] **永続化検証**: DB の状態変更をトランザクション内で検証し、ロールバックする検証
- [ ] **状態遷移検証**: 状態マシンの遷移が期待通りか検証
- [ ] **診断情報検証**: ログ、メトリクス、ヘルスチェックの詳細検証
- [ ] **スクリーンショット比較**: ベースライン画像とのピクセル比較
- [ ] **パフォーマンス検証**: レスポンスタイム、スループットの検証
- [ ] **セキュリティ検証**: 認証、認可、インジェクション対策の検証

## 制約

- [ ] **GUI ドライバの分離**: 現在 Web ランナーが GUI/CLI の両方を兼ねている
- [ ] **ブラウザ依存**: Playwright のブラウザ依存関係が大きい
- [ ] **並列実行**: シナリオの並列実行未対応
- [ ] **テストデータ管理**: テストデータのセットアップ/クリーンアップの標準化未対応
